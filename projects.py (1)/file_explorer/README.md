# Python File Explorer

A fundamental desktop file explorer built with Python and Tkinter.

## Features

- Folder tree sidebar
- File list with name, type, size, and modified date
- Back, forward, up, home, and refresh navigation
- Path bar and quick folder opening
- File name search/filter
- Double-click to open folders or launch files with the system default app
- Create folder, rename, delete, copy, cut, and paste
- Keyboard shortcuts for common actions

## Run

```bash
python app.py
```
